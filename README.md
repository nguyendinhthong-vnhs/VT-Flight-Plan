# VT-Flight-Plan
Vũng Tàu Auto Tool là chương trình hỗ trợ lập và quản lý ICAO Flight Plan (FPL), giúp tự động hóa việc nhập dữ liệu, tính toán thông tin chuyến bay, tra cứu sân bay/điểm bay, hiển thị đường bay trên bản đồ và xuất FPL. Phần mềm hướng đến nâng cao tốc độ, độ chính xác và hiệu quả trong công tác lập kế hoạch bay.
